# Sonal Roy — Portfolio

A clean, responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Sections
- Hero (with typing animation)
- About
- Skills (animated progress bars)
- Projects
- Contact (front-end form)
- Footer

## How to use

1. Edit `index.html` to update text, links, email, social profiles.
2. Edit `style.css` to change colors — main theme colors are CSS variables at the top of the file (`:root`).
3. Edit `script.js` to change typing texts (`textArray`) or form behavior.

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. Go to https://vercel.com → New Project → Import your GitHub repo.
3. Framework preset: **Other** (no build step needed).
4. Deploy — done!

## Contact Form

The contact form is front-end only (no backend). To make it actually send emails, connect it to a free service such as:
- Formspree (https://formspree.io)
- Web3Forms (https://web3forms.com)
- EmailJS (https://www.emailjs.com)
